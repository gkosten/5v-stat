# Корректировка результатов «5 вёрст»

Веб-инструмент для волонтёров локаций «5 вёрст»: сверка отсечек времени от нескольких секундомеров, исправление ошибок и подготовка итогового CSV для загрузки на сайт.

Открывается прямо в браузере (компьютер и телефон), работает офлайн, ничего не устанавливать не нужно. **Данные участников никуда не отправляются** — вся обработка происходит на вашем устройстве.

## Зачем это нужно

На старте один волонтёр фиксирует время финиша, другой выдаёт токены. Потом данные совмещаются — и рождаются типовые ошибки:

- двойные отсечки (один финиш зафиксирован дважды);
- пропущенные отсечки (секундомер не успел нажать кнопку);
- перепутанные соседние финиши («кто был первый, кто второй»);
- неверно выданные токены.

Раньше всё это правилось вручную прямо в CSV. Теперь — в наглядном интерфейсе с автопроверками.

## Как пользоваться

1. Откройте страницу по ссылке (см. ниже) — на компьютере или телефоне.
2. Нажмите **«Загрузить файлы»** и выберите один или несколько CSV от секундомеров.
3. Файлы появятся в виде чипов в панели «Секундомеры». Клик по чипу назначает файл **базовым** (отмечен ★): его строка `STARTOFEVENT` попадёт в итоговый экспорт. Крестик ✕ на чипе удаляет файл из сверки (например, если загрузили дважды или у секундомера слишком много ошибок).
4. Записи сведутся в таблицу по слотам. Для каждой записи можно:
   - **оставить** одну из отсечек, если несколько секундомеров разошлись (радиокнопка);
   - **отредактировать** итоговое время вручную (например, по фотофинишу);
   - **удалить** лишнюю запись (двойная отсечка);
   - **поменять местами** соседние записи кнопками ↑/↓ (классический случай «первый и второй поменялись»);
   - **вставить пустой слот** кнопкой +, если секундомер пропустил финиш.
5. Поле **«Пометка»** — только для вас: «муж в красной куртке», «мама Даши» и т. п. В экспорт пометки **не попадают**.
6. Нажмите **«Экспорт CSV»** — скачается файл в точности исходного формата: строка `STARTOFEVENT` из базового файла, сквозная нумерация, итоговые времена, строка `ENDOFEVENT`. Готово для загрузки на сайт.

## Автопроверки

Проблемные записи подсвечиваются, сверху в липкой панели — сводка счётчиков.

| Подсветка | Что означает | Что делать |
|---|---|---|
| Красная «дубль» | Две отсечки в одну секунду | Вероятно, двойное нажатие. Проверьте по фотофинишу, лишнюю удалите |
| Жёлтая «вплотную» | Соседние финишы ближе 2 секунд | Вероятная путаница «кто первый/второй». Сверьтесь с фотофинишем |
| Синяя «разрыв» | Больше 90 секунд между соседними финишами | Возможно, секундомер пропустил отсечку — вставьте пустой слот или проверьте запись |
| Оранжевая «расхождение» | Секундомеры дают разные времена для одного слота | Выберите верную отсечку радиокнопкой или отредактируйте вручную |
| Пустой слот | У файла нет отсечки, у базового — есть | Проверьте по фотофинишу: пропуск или реальный отрыв |

Пороги проверок (2 и 90 секунд) заданы константами в начале скрипта — их можно изменить под свою локацию.

## Важно знать

- **Правки не сохраняются между сессиями.** Перезагрузили страницу — всё сбросилось. Не закрывайте вкладку, пока не скачали итоговый CSV.
- **Совместного редактирования нет.** Каждый волонтёр правит свою копию. Договоритесь, кто «главный редактор» на старте, — остальные присылают ему правки текстом.
- **Приватность.** Файлы обрабатываются локально в браузере, ни на какие серверы не отправляются. Не публикуйте реальные файлы с данными участников в открытых местах (например, в Issues этого репозитория) — замените имена и номера на выдуманные.

## Как внести свой вклад

Помощь приветствуется! Чтобы всем было проще, придерживайтесь нескольких правил.

### Сообщить о проблеме или предложить идею
https://github.com/gkosten/5v-stat/issues
1. Откройте вкладку **Issues** в репозитории и нажмите **New issue**.
2. Опишите коротко: что делали → что получилось → что ожидали. Скриншот сильно помогает.
3. **Не прикладывайте реальные файлы участников** — замените имена и номера на выдуманные.

### Предложить правку кода
https://github.com/gkosten/5v-stat
1. Сделайте **fork** репозитория (кнопка в правом верхнем углу) — это ваша копия проекта.
2. Внесите изменения в своей копии. Правки удобнее вести в отдельной ветке, а не в `main`.
3. Откройте **Pull request** из вашей копии в оригинальный репозиторий и коротко опишите, что и зачем изменили.
4. Одно улучшение — один pull request: так ревью быстрее, а откатить неудачное проще.

### Чего делать не стоит

- Добавлять что-либо, что отправляет данные участников на внешние серверы. Вся ценность инструмента в том, что данные не покидают браузер волонтёра.
- Менять формат экспорта без обсуждения: на сайт «5 вёрст» файл загружается в строгом формате, любое изменение формата нужно сначала проверять на реальной загрузке.

### Идеи для развития

Если хотите помочь и не знаете с чего начать — вот направления из текущего плана:

- автосохранение сессии (чтобы правки не терялись при перезагрузке);
- сверка с журналом выдачи токенов;
- PWA-обёртка: установка на главный экран телефона как приложения.

## Правовая информация

- Этот проект — **частная инициатива волонтёра**, не связан с движением 5verst.ru и не одобрен его организаторами.
- Инструмент предоставляется «как есть», **без каких-либо гарантий**. Использование сервиса — на ваш страх и риск: перед загрузкой на сайт обязательно проверяйте итоговые результаты вручную.
- Название «5 вёрст» и связанные обозначения принадлежат организаторам движения 5verst.ru.
